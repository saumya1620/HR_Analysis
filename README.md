# HR Analytics — Employee Attrition & Workforce Analysis

An end-to-end HR analytics project using **SQL, Excel, and Tableau** to analyze employee attrition, workforce demographics, compensation, career progression, and employee experience.

## 🛠️ Tools Used

* **SQL** — Data cleaning, business analysis, CTEs & window functions
* **Excel** — PivotTables, KPIs, slicers & 5-page interactive dashboard
* **Tableau** — Single-page executive dashboard

## 📊 Analysis Covered

* Workforce distribution by department, job role and job level
* Attrition by department, job role, age, tenure and overtime
* Compensation analysis across departments, roles and job levels
* Experience vs. salary
* Career progression and promotion gaps
* Job satisfaction, performance and work-life balance
* Overtime vs. attrition using 100% stacked analysis

## 📌 Dataset

* **1,470 employees**
* **35 columns**
* **237 employees left**
* **1,233 employees stayed**
* **Overall attrition rate: 16.12%**
* No missing values or duplicate rows

> The dataset is a fictional/synthetic HR dataset and does not represent actual IBM employee data.
